## 입력 처리 예시

### 파일 경로 예시

**입력**: `/Users/lhysin/project/src/utils/helpers.ts`

**처리**: 파일을 읽고 TypeScript 코드 분석

**출력**:

```markdown
#.helpers.ts 유틸리티 함수

> TypeScript 유틸리티函数的 핵심 기능을 한 문장으로 요약합니다.

## 핵심 항목
<!-- 레퍼런스: 주요 함수/클래스 -->
- formatDate(date: Date): string
- parseJSON<T>(str: string): T
- debounce<T>(fn: T, delay: number): T

## 사용 제한
<!-- 레퍼런스: 주의 사항 -->
- 非同期 처리 시 예외 처리 필수
- parseJSON은 유효하지 않은 JSON에서 오류 발생

---

## 상세 설명

### 배경 및 근거
- 유틸리티 파일 목적
- 주요 의존성

### 예시
- formatDate 사용 예시
- parseJSON 사용 예시

### 문제 해결
- undefined/null 처리
- 타입 오류 해결

### 참고 자료
- TypeScript 공식 문서
```

### URL 예시

**입력**: `https://docs.example.com/api/auth`

**처리**: WebFetch로 페이지 내용 가져오기

**출력**: 페이지 내용 기반 생성된 문서

### 파일 내용 직접 입력

**입력**:

```markdown
# API 문서
## 인증
Bearer 토큰 사용
## 엔드포인트
GET /users
POST /users
```

**처리**: 마크다운 파싱 후 구조화
