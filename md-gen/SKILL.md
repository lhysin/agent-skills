# md-gen

원본 파일의 경로, URL, 또는 내용을 입력받아 일관된 마크다운 템플릿으로 변환합니다.

## 입력

다음 세 가지 방식으로 입력을 제공할 수 있습니다:

1. **파일 경로**: 로컬 파일의 경로를 지정합니다
   ```
   ~/project/docs/api-guide.md
   ./README.md
   ```

2. **URL**: 웹에서 콘텐츠를 가져옵니다
   ```
   https://docs.example.com/api-reference
   ```

3. **파일 내용**: 직접 마크다운 또는 텍스트 내용을 입력합니다
   ```markdown
   # 직접 입력한 내용
   이것은 파일의 전체 내용입니다...
   ```

## 템플릿 구조

생성되는 문서는 다음 구조를 따릅니다:

```markdown
# [문서 제목]

> [적용 범위]와 [핵심 원칙/목적]을 한 문장으로 요약합니다.

## [유형별 핵심 섹션]
<!-- 정책: 핵심 규칙 / 가이드: 필수 절차 / 레퍼런스: 핵심 항목 -->
- 항목 1
- 항목 2

## [유형별 제한 섹션]
<!-- 정책: 금지 사항 / 가이드: 주의 사항 / 레퍼런스: 사용 제한 -->
- 항목 1
- 항목 2

---

## 상세 설명

### 배경 및 근거
- 설계 배경
- 판단 근거

### 예시
- 코드 예시
- 설정 파일 예시

### 문제 해결
- 자주 발생하는 문제
- 트러블슈팅

### 참고 자료
- 관련 링크
- 외부 문서
```

## 문서 유형 판단

입력 내용을 분석하여 다음 유형 중 하나를 판단합니다:

| 유형 | 판단 기준 | 핵심 섹션 예시 | 제한 섹션 예시 |
|------|-----------|----------------|----------------|
| **정책** | 규칙, 금지 사항, 준수 요구사항 중심 | 핵심 규칙 3-5개 | 금지 사항 2-4개 |
| **가이드** | 절차, 방법론, 단계별 지침 중심 | 필수 절차 4-6개 | 주의 사항 3-5개 |
| **레퍼런스** | 참조 정보, 스펙, 설정값 중심 | 핵심 항목 5-8개 | 사용 제한 3-5개 |

## 변환 프로세스

### 1단계: 입력 처리

- **파일 경로**: 파일 내용을 읽습니다
- **URL**: WebFetch로 콘텐츠를 가져옵니다
- **파일 내용**: 직접 파싱합니다

### 2단계: 내용 분석

- 문서 유형 판단 (정책/가이드/레퍼런스)
- 제목 추출 또는 생성
- 핵심 규칙/절차/항목 식별
- 제한사항/주의사항/사용제한 추출

### 3단계: 템플릿 적용

- 제목 설정 (원본 제목이 없으면 내용 기반으로 생성)
- 요약문 작성 (적용 범위 + 핵심 목적)
- 유형에 맞는 핵심/제한 섹션 구성
- 상세 설명 섹션 작성

### 4단계: 출력

변환된 마크다운 문서를 반환합니다.

## 출력 예시

**입력**: `/Users/lhysin/project/README.md` (내용 생략)

**출력**:

```markdown

> 프로젝트 초기 설정 및 기본 사용법을 한 문장으로 요약합니다.

### 배경 및 근거

- 주요 기술 스택

### 예시

- 외부 문서
```

## 제한사항

- 이미지, 비디오 등 바이너리 콘텐츠는 처리하지 않습니다
- 매우 큰 파일 (>1MB)은 분할 처리될 수 있습니다
- 암호화/보안 관련 내용은 보호됩니다

## 오류 처리

입력 처리 중 실패 시 다음 기준에 따라 대응합니다:

### 파일 경로 실패
- **파일 없음**: 오류 메시지와 함께 스킬을 종료합니다. 원본 내용을 보존할 수 없습니다.
- **읽기 권한 없음**: 스킬을 종료합니다.

### URL 접근 실패
- **접근 불가 또는 시간 초과**: 원본 URL과 오류 내용을 그대로 반환합니다. 변환 없이 종료합니다.
- **리다이렉트 실패**: 최대 3회 리다이렉트 후 실패 시 원본 URL과 함께 종료합니다.

### 파싱 오류
- **잘못된 형식**: 파싱 가능한 부분까지 처리한 후, 처리 못한 부분을 경고 메시지와 함께 출력합니다.
- **빈 입력**: 스킬을 종료합니다.

### 큰 파일 처리
- **1MB 초과**: 분할 기준(섹션별 또는 1000줄 기준)을 적용합니다. 분할 후 각 파트별로 변환을 시도합니다.
- **분할 후에도 처리 실패**: 처리된 부분까지만 출력하고 남은 부분을 경고합니다.
